# Images du personnage

Les dessins de Capri et les icônes ne sont pas dans ce dépôt : le personnage ne m'appartient pas.
Ils viennent du projet d'origine, [mochiiwuff/capri-desktop](https://github.com/mochiiwuff/capri-desktop),
qui explique aussi comment les fabriquer (`tools/build-sprite.py`, `tools/build-cutins.py`).
